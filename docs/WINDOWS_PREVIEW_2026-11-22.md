# AI CutPro — запуск Windows-прототипа (22.11.2026)

## Получить сборку

Проверенная сборка .NET 8 для Windows x64 автоматически публикуется в GitHub Actions:

- [Build AI CutPro prototype — run 45053389145](https://github.com/manager1980ai-debug/ai-cutpro-public/actions/runs/45053389145)
- Внизу страницы **Artifacts**: скачать **AI-CutPro-Windows-Preview** (ZIP, около 40 МБ архив).
- Разархивировать ZIP в отдельную папку на Windows 10/11 x64.
- Запустить основной файл **AICutPro.App.exe**. Если Windows предупреждает о неизвестном издателе, это неподписанная тестовая сборка, а не коммерческий установщик. Перед запуском убедиться, что скачивание выполнено с указанного репозитория.
- Для теста открыть локальный DXF или воспользоваться экранными демонстрационными функциями. Не подключать контроллер станка и не использовать результаты для производственной резки.

Сборка создаётся командой `dotnet publish ... --runtime win-x64 --self-contained true`. **Установка .NET SDK пользователю не требуется.** Отдельного MSI/инсталлятора пока нет. Артефакт хранится 14 дней; следующие коммиты создают новые архивы.

## Граница готовности

Это текущий работающий по исходному коду CAD/DXF-прототип с ограниченными инструментами предварительного просмотра/редактирования. Не промышленный CAD/CAM. Никакой запуск плазменной резки, G-code, управление контроллером или подключение к станку здесь не допускаются. Сохраняемые ограничения длины и осей живут только в текущей DXF-сессии и её Undo/Redo, не в исходном DXF.

Полный этап 2 остаётся открытым: универсальная CAD-редактура, независимый набор производственных DXF, независимая сверка сторонним CAD-ядром, общий параметрический solver и согласованная 3D B-rep/STEP/STL, а также визуальная GUI-приёмка.
