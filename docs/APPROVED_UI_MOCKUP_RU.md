# Утверждённый визуальный макет AI CutPro

Статус: утверждён пользователем 22 ноября 2026 года.

Основой интерфейса является последняя согласованная версия макета: тёмно-синяя тема с ярко-голубыми акцентами, вкладка «Раскрой», центральное поле листа с десятью одинаковыми кронштейнами, боковые панели задания и параметров станка. **Не заменять оформление альтернативным дизайном без согласования.**

## Обязательные требования

- Один исходный геометрический объект для чертежа, 3D-модели, миниатюр, раскроя и управляющей траектории. Форма и число отверстий полностью совпадают.
- Нижние кнопки слева направо: **Ручное управление → Симуляция → Сохранить → Запуск резки**.
- Ручное управление: перемещение X/Y/Z, выбор шага и скорости, запись контрольных точек и положения листа.
- Симуляция: экранная траектория, проверка расположения на листе и безопасная проверка движения при поддержке оборудования.
- Резка запускается только после подтверждения оператора и проверки защит; физический аварийный останов независим от ИИ.
- После подтверждённого начала резки облачный голосовой ввод отключается автоматически ради экономии ресурсов; оператор может включить его вручную.
- Поддержка пользовательских станков с ручным профилем и совместимыми контроллерами.
