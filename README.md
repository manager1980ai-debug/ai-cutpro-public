# AI CutPro

Кроссплатформенный CAD/CAM-прототип по [утверждённому макету](docs/approved-ui-mockup.png) и [ТЗ v0.9](docs/TECHNICAL_SPECIFICATION_RU.md).

## Состояние

Первый исходный прототип: Avalonia UI (.NET 8) + отдельное геометрическое ядро. Есть визуальная раскладка **ограничивающих прямоугольников** деталей на листе 3000 × 1500 мм, расчёт занятой площади, пошаговая визуальная демонстрация и сохранение текстовой сводки. Это ещё **не промышленный нестинг**, не точная геометрия утверждённого кронштейна и не симулятор режущей головки.

**Запуск реальной резки отключён**. Драйверы станков, G-code, 3D, лицензирование, MCP и команды движения пока не реализованы. Реализован ограниченный **предварительный просмотр ASCII DXF** (LINE, CIRCLE, ARC, прямые LWPOLYLINE), а также базовый анализ простых замкнутых полигонов и круглых отверстий. Это не промышленный DXF/CAM импорт, дуги не допускаются к построению траекторий.

## Запуск для разработчика

Нужен .NET SDK 8 на Windows, macOS или Linux:

```bash
dotnet run --project src/AICutPro.App/AICutPro.App.csproj
```

Автоматическая проверка компиляции на трёх ОС настроена в GitHub Actions. До успешного выполнения проверки сборка считается непроверенной.

## Ограничения

Площадь использования прямоугольников не учитывает отверстия и контур детали; она отличается от показанных на утверждённом художественном макете 92%. Нельзя формировать по этим данным реальные управляющие программы.

Дальнейшие этапы: расширение DXF, проверка CAD-геометрии, производственный нестинг, согласованные 2D/3D/траектории, виртуальная модель оборудования, MCP, подписанные годовые лицензии и адаптеры контроллеров.
